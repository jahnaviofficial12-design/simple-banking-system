# simple-banking-system
A Python-based Banking System mini project that simulates essential banking operations, including account management, secure login, balance inquiries, deposits, withdrawals, fund transfers, transaction history, and PIN management.

## Objective

The objective of this project is to combine basic Python concepts to create a simple real-world banking application.

## Features

- Create a bank account
- Generate a unique account number
- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout

## Python Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Lists
- Dictionaries
- String Operations
- Modules

## Modules Used

- `random` – to generate account numbers
- `datetime` – to record transaction date and time

## How to Run

1. Open the project in Python or GitHub Codespaces.
2. Run `banking_system.py`.
3. Select an option from the main menu.
4. Create an account before logging in.
5. Use the account menu to perform banking operations.
